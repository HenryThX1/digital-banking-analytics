# Power BI

Adicione aqui uma versão publicável do relatório Power BI (`.pbix`) **somente após** remover referências a credenciais, informações privadas, links internos e identidade visual que implique vínculo institucional.

## Checklist antes do upload

- [ ] Relatório funciona com fontes acessíveis ao leitor ou contém dados sintéticos importados.
- [ ] Não há credenciais/tokens no M, parâmetros, scripts SQL ou conexões.
- [ ] Navegação, gráficos, YoY, NPL e retenção respondem aos filtros.
- [ ] Marca própria e aviso de projeto independente.
- [ ] Datas-base e unidades monetárias claramente identificadas.
- [ ] O arquivo cabe no método de upload; caso contrário, usar Git LFS ou link para download do Release.
- [ ] README fornece link para demonstração e capturas.

**Publicação no Power BI Service:** o recurso "Publicar na Web" deixa o relatório e o modelo acessíveis ao público. Usar somente dados que você pode disponibilizar integralmente.
